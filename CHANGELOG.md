# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 — 2026-09-08

- Added scroll-to-video-time mapping with normalized, frame-rate-independent smoothing.
- Added connected Framer scene components with crossfade and vertical offset controls.
- Added desktop/mobile clip and poster selection.
- Added cache-safe native media listeners and immediate `readyState` checks.
- Added initial synchronization for reloads and restored scroll positions.
- Added guarded seeking, coarse-pointer handling, and iOS media unlocking.
- Added a reduced-motion static state.
- Added video-encoding and Framer-setup documentation.
