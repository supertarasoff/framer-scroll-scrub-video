# Contributing

Bug reports and focused pull requests are welcome.

## Before opening an issue

Please include:

- Framer Preview or published-site URL when possible;
- browser and operating system;
- desktop or mobile breakpoint;
- video codec, dimensions, frame rate, duration, file size and keyframe interval;
- number of connected scenes;
- steps that reproduce the problem from a fresh load.

Do not include private Framer remix links, client assets, credentials, or licensed media you cannot redistribute.

## Pull requests

Keep the component dependency-free unless a dependency is essential and discussed first. Preserve:

- native document scrolling;
- poster-first behavior;
- reduced-motion handling;
- desktop/mobile media controls;
- cleanup for every listener and animation frame;
- Framer Property Controls compatibility.

Test changes in Framer Preview and on a published site at desktop and mobile widths. Also test a reload in the middle of the sticky section.
